### 4. wx.cloud.extend.AI

| 项目 | v1.0 说法 | v2.0 说法 | 验证结论 |
|------|------|------|------|
| API 是否存在 | 未提及（用云函数调LLM） | "客户端直调，SSE流式" | **v2 正确且更优**。API 存在且支持流式。 |
| 基础库要求 | — | 3.15.1（付费模型） | **正确**。官方 QuickStart 明确要求基础库 ≥ 3.15.1。 |
| 是否绕过云函数 | — | "实时对话不走云函数" | **正确**。`wx.cloud.extend.AI` 由小程序端直调云开发 AI 能力。 |

**关键证据**（官方文档 QuickStart）：
```javascript
// 基础库 ≥ 3.15.1
const model = wx.cloud.extend.AI.createModel("cloudbase");
const res = await model.streamText({
  data: { model: "hy3-preview", messages: [...] }
});
for await (const text of res.textStream) { ... }
```

**争议点**：v1 说云函数编排对话，v2 说客户端编排。实际选择取决于：
- 客户端编排：延迟低（直调混元），但 system prompt 存在于前端代码（可反编译）
- 云函数编排：延迟高（多一跳），但 prompt 安全

**可信度**：★★★★★（官方 QuickStart 文档确认）

## 三、v2.0 → v3.0 合并建议

### 总体判断

v2 的修正质量很高，90%的论断经交叉验证站得住脚。建议以 v2 为基，做以下3处修正后产出 v3：

1. **ChatUI Kit**：修改为"优先使用官方 `ai-chat-view` 组件（W1验证），不可用则降级自建"
2. **CloudBase 资源点**：填入已确认的 40,000点/月
3. **架构说明**：补充客户端编排 vs 云函数编排的权衡表

### 关于 v1 中仍有价值的内容

v1 中的以下内容建议保留并入 v3：
- 对话引擎的伪代码示意（清晰易懂）
- 三层思辨场的叙事逻辑
- 评分算法的详细拆解
- 演示视频分镜
