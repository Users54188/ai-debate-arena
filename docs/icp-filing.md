# 小程序备案信息说明

> 根据《互联网信息服务管理办法》《非经营性互联网信息服务备案管理办法》《生成式人工智能服务管理暂行办法》，面向国内提供生成式 AI 服务的小程序上线前必须完成 ICP 备案与算法备案。**未完成备案不得对外提供服务。**

## 1. ICP 备案（小程序主体备案）

| 项 | 说明 |
|---|---|
| 主体 | 小程序开发者主体（个人 / 企业 / 个体工商户等） |
| 流程 | 微信公众平台 → 设置 → 基本设置 → 微信认证 → ICP 备案 |
| 周期 | 通常 7-20 个工作日 |
| 必备材料 | 主体证件、负责人身份证、域名（如有）、小程序名称与简介 |
| 显示位置 | 小程序"关于"页面（系统提供）、详情页底部 |

## 2. 算法备案（生成式 AI 专项）

依据《生成式人工智能服务管理暂行办法》第 7 条、第 17 条，提供生成式 AI 服务必须进行算法备案。

| 项 | 说明 |
|---|---|
| 备案系统 | [互联网信息服务算法备案系统](https://beian.cac.gov.cn) |
| 主体 | 服务提供者（小程序开发者主体） |
| 必备材料 | 算法机制机理说明、算法评估报告、用户权益保护制度、拟公开内容 |
| 周期 | 通常 30-60 个工作日 |
| 显示位置 | 小程序"关于"页面或《算法服务说明》单独页面 |

⚠️ **本项目使用了 CloudBase AI（cloudbase 大模型）。若 CloudBase 已完成大模型的整体算法备案，开发者仍需作为"服务提供者"完成自身的算法备案（不能仅依赖云厂商的备案）。请上线前与微信开放平台沟通最新政策。**

## 3. 大模型服务备案（深度合成）

若服务涉及深度合成（图像生成、语音合成等），还需依据《互联网信息服务深度合成管理规定》进行深度合成服务备案。

- 当前项目仅使用文本生成，未涉及深度合成。
- 若后续接入图像/语音能力，需重新评估。
