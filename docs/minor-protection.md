# 未成年人保护说明

> 本文档用于满足《未成年人网络保护条例》《未成年人节目管理办法》《关于防止未成年人沉迷网络游戏的通知》等法规对面向未成年人或可能被未成年人使用的小程序的合规要求。**上线前必须完成以下动作并在代码中落实。**

## 1. 用户年龄识别

- 当前版本**不主动收集用户年龄信息**（按 PIPL 最小必要原则）。
- 若用户在登录时通过微信授权获得 `nickName`/`avatar`，不进行年龄推断。
- 若后续接入实名认证或青少年模式，需要新增弹窗确认。

## 2. 青少年模式（暂未实现，规划中）

| 项 | 说明 |
|---|---|
| 入口 | 用户主动开启：在 `pages/profile/index` 增加"青少年模式"按钮 |
| 时段限制 | 每日 22:00 - 次日 06:00 不可使用（默认值，可配置） |
| 时长限制 | 每日累计使用 ≤ 40 分钟 |
| 内容限制 | 青少年模式下仅允许 L1 单人苏格拉底模式，禁用 L2/L3 与历史/排行 |
| 提示弹窗 | 进入青少年模式时提示"已为你开启青少年模式，每日使用时长有限" |

⚠️ 当前版本未实现青少年模式。上线前需评估：

- 是否面向未成年人运营（参考类目资质）
- 是否需调用 `wx.openIsPrivacyContractNeedAgree` 等接口
- 是否需要在 `pages/login/index` 添加年龄确认弹窗

## 3. 防沉迷提示

- L1/L2/L3 模式下，连续对话 ≥ 30 分钟时，提示"已思辨较久，建议休息一下"。
- 此提示在 `utils/ai-stream.js` 或各页面 `onShow` 中累积计时实现（暂未实现）。

## 4. 内容安全

- 已实现 `msgSecCheck` 双向审核（输入场景 2 + AI 输出二次审核），覆盖未成年人有害内容防护。
- 危险话题（自残、暴力、色情等）由 `prompts/socrates.md` 终止指令兜底（AI 主动终止并提示寻求现实帮助）。

## 5. 数据保护

- 未成年人数据按《个人信息保护法》第 31 条处理：**需要监护人同意**。
- 当前未区分成年/未成年用户数据，统一按 30 天 TTL 自动清理（`cleanupData` 云函数）。
- 如收到监护人投诉要求删除未成年子女数据，由 `cleanupTestData` 工具按 openid 精准清理。
